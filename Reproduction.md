# Missing steps to setup LAE-DINO training environment
```
conda activate lae
cd LAE-DINO_Reprod
pip uninstall -y opencv-python      # To prevent a conflict between opencv-python and opencv-contrib-python
pip install -r missing_requirements.txt
```

`missing_requirements.txt` was generated by diffing `lae_requirements.txt` against `pip list
--format=freeze` in the `lae` env, keeping only packages absent from the env (already-installed /
version-matched packages, including the CUDA-specific torch stack, are excluded on purpose).

Two entries worth a second look before installing:
- `mmyolo` — not imported anywhere on this training path; safe to skip if you want a leaner env.

# BERT Weight download and create symlink
```
cd LAE-DINO_Reprod

# Download the weights to scratch (limited disk quota on the local/home dir)
mkdir -p /go/to/scratch/bert-base-uncased
huggingface-cli download --resume-download google-bert/bert-base-uncased --local-dir /go/to/scratch/bert-base-uncased

# Symlink weights/bert-base-uncased to the scratch copy
ln -s /go/to/scratch/bert-base-uncased weights/bert-base-uncased
```

2. Footprint: Per-block latency
    - `extract_feat`: Extract an input mage feature
    - `tokenize`: CPU-level. Input text tokenization for the language model.
    - `language_model`: Extract an input text feature
    - `pre_transformer`: Data preparation before VisGT (e.g., flattening multi-level feature maps, building masks/positional embeddings/valid_ratios)
    - `visgt`: Visual-Guided Text Prompt Learning
    - `fusion_encoder`: GroundingDINO Feature Enhancer (e.g., Image-to-Text Cross-Attn followed by Text-to-Image Cross-Attn)
    - `decoder`: Pre-decoder(e.g., proposal generation, top-k selection, and query embedding) + forward decoder (e.g., CrossModality-to-Image Cross-Attn followed by CrossModality-to-Text Cross Attn)
    - `bbox_head_predict`: Decoder query outputs to (bbox, class) format
